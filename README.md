# Sumit Prasad — Portfolio

A dark, premium, engineering-focused portfolio built as a lightweight static site for easy GitHub Pages deployment.

## Before launch

Edit `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_LINKEDIN`
- `YOUR_GITHUB`

Optionally add a resume link/button and profile image.

## Run locally

Because this is static HTML/CSS/JS, you can simply open `index.html`, or serve it with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

Create a repository, copy these three site files into the repository root, commit, push, and enable GitHub Pages from repository Settings → Pages → Deploy from branch → `main` / root.
